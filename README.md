# Mon Petit Patrimoine : les versions publiées

**Mon Petit Patrimoine** est une application Windows pour suivre son patrimoine personnel : PEA, compte-titres, assurance-vie, livrets réglementés et immobilier, au même endroit. Tout reste sur votre ordinateur : pas de compte à créer, aucun identifiant bancaire, aucun serveur.

Ce dépôt ne contient que les installeurs des versions publiées (rubrique « Releases »), utilisés par l’application pour signaler une nouvelle version. Il ne contient ni le code ni aucune donnée.

## Télécharger l’application

Passez par le site, qui propose toujours la dernière version et explique l’installation : **https://monpetitpatrimoine.github.io**

- [Fonctionnalités](https://monpetitpatrimoine.github.io/fonctions.html)
- [Tarif : essai gratuit de 30 jours, puis licence à vie](https://monpetitpatrimoine.github.io/prix.html)
- [Questions fréquentes](https://monpetitpatrimoine.github.io/questions.html)

À l’installation, Windows peut afficher « Windows a protégé votre ordinateur » : l’installeur n’est pas signé. Cliquez sur « Informations complémentaires », puis « Exécuter quand même ».
