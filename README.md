# Mon Petit Patrimoine : les versions publiées

**Mon Petit Patrimoine** est une application Windows et Mac pour suivre son patrimoine personnel : PEA, compte-titres, assurance-vie, livrets réglementés et immobilier, au même endroit. Tout reste sur votre ordinateur : pas de compte à créer, aucun identifiant bancaire, aucune donnée financière envoyée.

Ce dépôt ne contient que les installeurs des versions publiées (rubrique « Releases »), utilisés par l’application pour signaler une nouvelle version. Il ne contient ni le code ni aucune donnée.

## Télécharger l’application

Passez par le site, qui propose toujours la dernière version et explique l’installation : **https://monpetitpatrimoine.net**

- [Fonctionnalités](https://monpetitpatrimoine.net/fonctions.html)
- [Tarif : essai gratuit de 30 jours, puis licence](https://monpetitpatrimoine.net/prix.html)
- [Questions fréquentes](https://monpetitpatrimoine.net/questions.html)

Sur Windows, l’installation peut afficher « Windows a protégé votre ordinateur » : l’installeur n’est pas signé. Cliquez sur « Informations complémentaires », puis « Exécuter quand même ».
